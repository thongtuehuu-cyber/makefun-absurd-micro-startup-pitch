One sentence pitching an absurdly specific micro-startup for lazy AI agents, for the [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) bounty on make.fun. ## Run it

python3 main.py
